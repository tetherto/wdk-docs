BOB Gateway connects WDK accounts to a routing service for Bitcoin, EVM and TRON asset routes. You can discover chains and tokens, preview an exact-input quote, submit the source transaction and track the resulting order.

These pages cover `@gobob/wdk-protocol-swidge-gateway@0.5.0`. For Node.js 24, use 24.22.1 or later in the 24.x line; see [installation](/sdk/swidge-modules/swidge-bob/usage#installation) for prerequisites.

## How a route runs

1. Discover the gateway's chain and token identifiers, then request a quote for an input amount and destination.
2. Show the input, destination token, recipient, output estimate and fees to the user.
3. Complete any token approval required by the source account.
4. Call `swidge()`. It requests a fresh quote, checks the configured bounds and creates an order before submitting the source transaction.
5. Retain the order ID and transaction hashes, then query settlement separately.

The earlier quote is a preview, not a route reserved for execution. Set `minAmountOut` and the applicable fee limits on the execution request to constrain the fresh quote. See [execution boundaries](/sdk/swidge-modules/swidge-bob/guides/execute-swidge#confirm-and-handle-approvals) for what those checks establish.

## Capabilities and limits

- Only exact-input requests are supported. Use `fromTokenAmount`; `toTokenAmount` is rejected.
- Discovery reports gateway routes, not guaranteed execution support for every returned chain. Source execution uses Bitcoin, EVM or TRON account methods.
- An accountless instance can discover routes, quote with an explicit recipient and retrieve status. Executing, checking allowances and simulating require the relevant account methods.
- `getRequiredApproval()` may create an unfunded order and returns an unbounded allowance when approval is needed. The application submits and confirms approval transactions.
- `simulateSwidge()` creates an unfunded order; on Bitcoin it also signs a transaction without returning its signed bytes. It does not broadcast.
- A source transaction hash does not establish destination delivery. Reconcile an uncertain submission before sending again.
- The package's source-transaction checks bound the source token, amount and certain native charges. Provider routing and destination execution still depend on BOB Gateway.

Use [runtime discovery](/sdk/swidge-modules/swidge-bob/usage#discover-chains-and-tokens) instead of maintaining a fixed network or token inventory. A token's presence does not establish liquidity or an executable route for a particular amount.
