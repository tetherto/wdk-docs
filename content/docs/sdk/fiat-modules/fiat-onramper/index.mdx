Use the Onramper fiat module to quote a crypto purchase or sale and open the hosted checkout from your application. Your backend signs the widget URL. The user completes checkout with a payment provider through the widget.

This guide covers [`@onramper/wdk-protocol-fiat-onramper@0.2.0`](https://www.npmjs.com/package/@onramper/wdk-protocol-fiat-onramper/v/0.2.0) for browsers, Node.js 20.19.0 or later, and Bare. React Native is outside the scope of this release.

## Integration flow

1. Ask Onramper to provision your partner account for the WDK channel and issue a publishable key.
2. Configure a backend signing endpoint. Use the publishable key to discover asset codes and request quotes from the client.
3. Call `buy()` or `sell()` to get a signed URL and hand the user off to the widget. Review the final amounts and fees in checkout.
4. For status lookups, provision checkout sessions and add a backend endpoint that returns a fresh session token.

You can give the module a WDK account to supply the default recipient or refund address. The module reads the address without asking the account to sign.
