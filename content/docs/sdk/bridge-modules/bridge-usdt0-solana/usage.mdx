# Usage

The [@tetherto/wdk-protocol-bridge-usdt0-solana](https://www.npmjs.com/package/@tetherto/wdk-protocol-bridge-usdt0-solana) package bridges native USD₮ from Solana to Ethereum, Arbitrum, Celo, TON, and TRON. Use the guides below for setup, standard and gasless bridging, and error handling.

<Cards>
<Card title="Get Started" href="/sdk/bridge-modules/bridge-usdt0-solana/guides/get-started">
Install the package, attach a signing or read-only Solana account, and register through WDK Core.
</Card>
<Card title="Bridge Tokens" href="/sdk/bridge-modules/bridge-usdt0-solana/guides/bridge-tokens">
Quote and send to EVM, TON, and TRON recipients, confirm the transaction, and cap fees.
</Card>
<Card title="Bridge with a Gasless Account" href="/sdk/bridge-modules/bridge-usdt0-solana/guides/bridge-gasless">
Bridge without holding SOL through a Kora paymaster, and configure the node to allow it.
</Card>
<Card title="Handle Errors" href="/sdk/bridge-modules/bridge-usdt0-solana/guides/handle-errors">
Interpret bridge failures and dispose of signing material safely.
</Card>
</Cards>
