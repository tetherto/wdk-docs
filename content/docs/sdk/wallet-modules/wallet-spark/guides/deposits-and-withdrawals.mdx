## Get a Single-Use Deposit Address

1. Call [`account.getSingleUseDepositAddress()`](/sdk/wallet-modules/wallet-spark/api-reference).
2. Send Bitcoin to the returned on-chain address and wait for confirmation.

You can generate a one-time Bitcoin deposit address using [`account.getSingleUseDepositAddress()`](/sdk/wallet-modules/wallet-spark/api-reference):

```javascript title="Single-Use Deposit Address"
const depositAddress = await account.getSingleUseDepositAddress()
console.log('Send Bitcoin to:', depositAddress)
```

## Claim Deposits

1. Identify the Bitcoin transaction id that funded the deposit.
2. Call [`account.claimDeposit()`](/sdk/wallet-modules/wallet-spark/api-reference) with that id.

You can credit the wallet after the deposit confirms using [`account.claimDeposit()`](/sdk/wallet-modules/wallet-spark/api-reference):

```javascript title="Claim Single-Use Deposit"
const txId = 'f4184fc596403b9d638783cf57adfe4c75c605f6356fbc91338530e9831e9e16'
const walletLeaves = await account.claimDeposit(txId)
console.log('Deposit claimed:', walletLeaves)
```

### 1. (optional) Use a static deposit address

Get a reusable Bitcoin address with [`account.getStaticDepositAddress()`](/sdk/wallet-modules/wallet-spark/api-reference#getstaticdepositaddress). After the deposit confirms, identify the output paying this address and verify its amount in satoshis.

Request a [claim quote](/sdk/wallet-modules/wallet-spark/api-reference#getclaimstaticdepositquoteoptions). The example uses the transaction ID, output index and value that your application verified against the Bitcoin transaction.

```javascript title="Quote a Static Deposit Claim"
const quote = await account.getClaimStaticDepositQuote({
  txId: verifiedDeposit.txId,
  outputIndex: verifiedDeposit.outputIndex,
  depositAmountSats: verifiedDeposit.amountSats
})

if (quote.transactionId !== verifiedDeposit.txId ||
    quote.outputIndex !== verifiedDeposit.outputIndex ||
    !Number.isSafeInteger(quote.creditAmountSats) ||
    quote.creditAmountSats <= 0 ||
    quote.creditAmountSats > verifiedDeposit.amountSats) {
  throw new Error('Claim quote does not match the verified deposit')
}

console.log('Credit in satoshis:', quote.creditAmountSats)
console.log('Claim fee in satoshis:', quote.claimFeeSats)
```

The displayed fee depends on the output amount you supplied. At claim time the SDK reads the Bitcoin output value and subtracts the freshly quoted credit to check the fee ceiling. The final credit can differ from the preview.

<Callout type="warn">
Claiming gives the Spark Service Provider the deposit's secret key and cannot be undone. The claim selects the first output paying any of the account's static deposit addresses. Use this flow for a transaction with one such output.
</Callout>

Pass the fee ceiling your caller approved when invoking [`claimStaticDeposit()`](/sdk/wallet-modules/wallet-spark/api-reference#claimstaticdeposittxid). The returned transfer ID is a Spark identifier.

```javascript title="Claim With an Approved Fee Cap"
if (!Number.isSafeInteger(approvedMaxFeeSats) || approvedMaxFeeSats < 0) {
  throw new Error('Provide an approved fee cap in whole satoshis')
}

const { transferId } = await account.claimStaticDeposit(verifiedDeposit.txId, {
  maxFeeSats: approvedMaxFeeSats
})
console.log('Spark transfer ID:', transferId)
```

If the fresh fee exceeds the cap, the claim throws [`StaticDepositFeeExceededError`](/sdk/wallet-modules/wallet-spark/api-reference#staticdepositfeeexceedederror). Review the new fee with the caller before retrying.

<Callout type="info">
You can list unused single-use addresses with [`account.getUnusedDepositAddresses()`](/sdk/wallet-modules/wallet-spark/api-reference). The method returns a paginated result with `depositAddresses` and `offset` fields.
</Callout>

## Query Static Deposit Addresses

You can list all existing static deposit addresses using [`account.getStaticDepositAddresses()`](/sdk/wallet-modules/wallet-spark/api-reference):

```javascript title="Query Static Deposit Addresses"
const addresses = await account.getStaticDepositAddresses()
console.log('Static deposit addresses:', addresses)
```

## Query UTXOs for a Deposit Address

You can check confirmed UTXOs for a specific deposit address using [`account.getUtxosForDepositAddress()`](/sdk/wallet-modules/wallet-spark/api-reference):

```javascript title="Query UTXOs"
const result = await account.getUtxosForDepositAddress({
  depositAddress: 'bc1q...'
})
console.log('Confirmed UTXOs:', result.utxos)
console.log('Offset:', result.offset)
```

## Withdraw to Bitcoin Layer 1

1. Choose a Bitcoin `onchainAddress` and `amountSats`.
2. Set [`withdrawMaxFee`](/sdk/wallet-modules/wallet-spark/configuration#withdrawal-fee-limit) when creating the wallet if you need a quoted-fee limit, in satoshis.
3. Request a cooperative exit quote with [`account.quoteWithdraw()`](/sdk/wallet-modules/wallet-spark/api-reference).
4. Call [`account.withdraw()`](/sdk/wallet-modules/wallet-spark/api-reference) with the destination, amount, and exit speed.

You can request a withdrawal fee quote using [`account.quoteWithdraw()`](/sdk/wallet-modules/wallet-spark/api-reference):

```javascript title="Quote Withdrawal"
const feeQuote = await account.quoteWithdraw({
  withdrawalAddress: 'bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh',
  amountSats: 100000
})
console.log('Withdrawal fee quote:', feeQuote)
```

You can initiate the withdrawal using [`account.withdraw()`](/sdk/wallet-modules/wallet-spark/api-reference):

```javascript title="Withdraw to On-Chain Bitcoin"
const withdrawal = await account.withdraw({
  onchainAddress: 'bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh',
  amountSats: 100000,
  exitSpeed: 'MEDIUM'
})
console.log('Withdrawal request:', withdrawal)
```

[`withdraw()`](/sdk/wallet-modules/wallet-spark/api-reference#withdrawoptions) fetches a new quote and checks the selected speed's L1 broadcast fee plus user fee against `withdrawMaxFee`. A greater fee throws `MaximumFeeExceededError`; equality is allowed. The earlier quote is for inspection and is not the quote used for this check.
