Install the [published package](https://www.npmjs.com/package/@tetherto/wdk-wallet-multisig-squads/v/1.0.0-beta.2), then follow the guide for your task.

<Cards>
<Card title="Get Started" href="/sdk/wallet-modules/wallet-multisig-squads/guides/get-started">Connect a seed-derived member and distinguish the multisig from its vault.</Card>
<Card title="Deploy a Multisig" href="/sdk/wallet-modules/wallet-multisig-squads/guides/deploy-multisig">Create a multisig with an agreed member set and threshold.</Card>
<Card title="Manage Proposals" href="/sdk/wallet-modules/wallet-multisig-squads/guides/manage-proposals">Quote, propose, approve and execute vault payments.</Card>
<Card title="Manage Owners" href="/sdk/wallet-modules/wallet-multisig-squads/guides/manage-owners">Propose member and threshold changes with explicit permissions.</Card>
<Card title="Coordinate Approvals" href="/sdk/wallet-modules/wallet-multisig-squads/guides/coordinate-approvals">Optionally gather approvals into a shared transaction.</Card>
<Card title="Handle Errors" href="/sdk/wallet-modules/wallet-multisig-squads/guides/handle-errors">Handle failed votes, stale state, fee limits and disposal.</Card>
</Cards>

All examples take cluster, member, vault and recipient values from your application's configuration. Review those values and the full transaction payload before signing. Classic SPL token support does not include Token-2022.
