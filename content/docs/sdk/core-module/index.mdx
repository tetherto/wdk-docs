WDK Core registers wallet managers, protocols, and middleware through one interface. The reference covers `@tetherto/wdk@1.0.0-beta.23`.

Add [`@tetherto/wdk-policies`](/sdk/core-module/guides/transaction-policies) to evaluate local ALLOW and DENY rules before account or protocol methods execute.

The base-wallet reference also covers `@tetherto/wdk-wallet@1.0.0-beta.26`, including the public [account configuration getter](/sdk/core-module/api-reference#account-configuration), signer disposal contracts, and multisig interfaces. This is a separate package from the WDK orchestrator; see the [base-wallet compatibility notes](/sdk/core-module/api-reference#base-wallet-signer-contracts).

Use WDK Core to:

- Register wallet managers for the chains your app supports.
- Attach protocol providers to accounts globally or per account.
- Decorate accounts with middleware before they reach the application.
