WDK Core is the main runtime for registering and managing wallet, protocol, middleware, and transaction policy modules through one interface.

The Core reference covers `@tetherto/wdk@1.0.0-beta.21`. Governed references reject function, accessor, and prototype changes through the proxy. See the [transaction policy guide](/sdk/core-module/guides/transaction-policies) for captured account-path bindings, method coverage, registration, simulation, and account overrides.

The base-wallet reference also covers `@tetherto/wdk-wallet@1.0.0-beta.24`, including rejection of signer registration after disposal and the updated multisig account contract. This is a separate package from the WDK orchestrator; see the [base-wallet migration notes](/sdk/core-module/api-reference#base-wallet-signer-contracts).
<Callout type="warn">
The transaction policy engine is experimental and not production ready. Its local checks do not isolate signing authority from a compromised agent environment. Review the [policy security boundary](/sdk/core-module/guides/transaction-policies#security-boundary) before relying on these controls.
</Callout>

Use WDK Core to:

- Register wallet managers for the chains your app supports.
- Attach protocol providers to accounts globally or per account.
- Decorate accounts with middleware before they reach the application.
- Register local transaction policies that allow, deny, or simulate write operations before they execute.
