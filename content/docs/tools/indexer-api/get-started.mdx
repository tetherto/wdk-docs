## Quick Example

Query the USD₮ balance of your intended Ethereum wallet. Replace `YOUR_WALLET_ADDRESS` with that wallet's address and set `WDK_INDEXER_API_KEY` in your environment.

<Tabs items={["curl", "JavaScript"]}>
<Tab value="curl">
```bash
WALLET_ADDRESS='YOUR_WALLET_ADDRESS'
curl --fail-with-body "https://wdk-api.tether.io/api/v1/ethereum/usdt/${WALLET_ADDRESS}/token-balances" \
     -H "x-api-key: ${WDK_INDEXER_API_KEY}"
```
</Tab>
<Tab value="JavaScript">
```javascript
// Run as a Node.js ES module using its built-in fetch.
const address = 'YOUR_WALLET_ADDRESS';
const apiKey = process.env.WDK_INDEXER_API_KEY;
if (!apiKey) throw new Error('Set WDK_INDEXER_API_KEY before making a request');

const response = await fetch(
  `https://wdk-api.tether.io/api/v1/ethereum/usdt/${encodeURIComponent(address)}/token-balances`,
  { headers: { 'x-api-key': apiKey } },
);
if (!response.ok) throw new Error(`Indexer request failed: HTTP ${response.status}`);
console.log(await response.json());
```
</Tab>
</Tabs>
