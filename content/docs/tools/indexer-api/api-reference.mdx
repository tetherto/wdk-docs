### GET /api/v1/health

**Deep health check endpoint**

Checks internal dependencies and blockchain indexer sync status. Returns HTTP 200 only when the overall status is \`healthy\`. Returns HTTP 503 for any non-healthy overall status (\`degraded\` or \`unhealthy\`), so readiness probes and load balancers can rely on the HTTP status code alone.

**Authentication:** Public endpoint.

**Example request**

Replace path placeholders and the API key before running.

```bash
curl --request GET 'https://wdk-api.tether.io/api/v1/health'
```

**Responses**

| Status | Description |
| --- | --- |
| ` 200 ` | Default Response |
| ` 503 ` | Default Response |

### GET /api/v1/chains

**Get supported blockchains and tokens**

Returns the list of all supported blockchains and their available tokens. Endpoint to discover valid blockchain and token combinations before calling other endpoints. This endpoint reads directly from the server configuration and requires no authentication.

**Authentication:** Public endpoint.

**Example request**

Replace path placeholders and the API key before running.

```bash
curl --request GET 'https://wdk-api.tether.io/api/v1/chains'
```

**Responses**

| Status | Description |
| --- | --- |
| ` 200 ` | List of supported blockchains with their tokens and case sensitivity rules |
| ` 500 ` | Internal Server Error - indexer service unavailable or unexpected failure |

**Response fields · HTTP 200 · application/json**

<div className="indexer-fields">

| ` $.chains[].tokens[] ` | string | — |
| ` $.chains[].caseSensitive ` | object | Case sensitivity rules. If present, addresses are preserved as-is (case-sensitive). If absent, addresses are automatically lowercased. |

### GET /api/v1/\{blockchain\}/\{token\}/\{address\}/token-transfers

**Get token transfers for an address**

Retrieve the token transfer history for a specific wallet address on a given blockchain. Returns incoming and outgoing transfers sorted by block number.

**Authentication:** ` X-API-KEY ` header required.

**Parameters**

<div className="indexer-fields">

| Name | Type | Details |
| --- | --- | --- |
| ` limit ` (query) | integer | Required: No. Maximum number of transfers to return. Minimum: ` 1 `. Maximum: ` 1000 `. Default: ` 10 `. |
| ` fromTs ` (query) | integer | Required: No. Start timestamp in milliseconds (inclusive). Use 0 to query from the beginning. Minimum: ` 0 `. Default: ` 0 `. |
| ` toTs ` (query) | integer | Required: No. End timestamp in milliseconds (inclusive). Omit to query up to the latest available data. Minimum: ` 0 `. |
| ` blockchain ` (path) | string | Required: Yes. Blockchain network identifier. Use GET /api/v1/chains to see all available options. Allowed values: ` "ethereum" `, ` "arbitrum" `, ` "avalanche" `, ` "polygon" `, ` "plasma" `, ` "sepolia" `, ` "tron" `, ` "ton" `, ` "bitcoin" `, ` "spark" `. |
| ` token ` (path) | string | Required: Yes. Token identifier. Must be a valid token for the specified blockchain. Allowed values: ` "usdt" `, ` "xaut" `, ` "usat" `, ` "btc" `. |
| ` address ` (path) | string | Required: Yes. Wallet address to query. Format varies by blockchain (e.g. 0x... for EVM, bc1... for Bitcoin, T... for Tron). Min length: ` 1 `. |

</div>

**Example request**

Replace path placeholders and the API key before running.

```bash
curl --request GET 'https://wdk-api.tether.io/api/v1/{blockchain}/{token}/{address}/token-transfers' \
  --header 'X-API-KEY: <api-key>'
```

**Responses**

| Status | Description |
| --- | --- |
| ` 200 ` | Token transfer history for the queried address |
| ` 400 ` | Bad Request - invalid parameters, address format, blockchain, or token |
| ` 401 ` | Unauthorized - expired API key |
| ` 403 ` | Forbidden - missing or invalid API key |
| ` 429 ` | Too Many Requests - rate limit exceeded |
| ` 500 ` | Internal Server Error - indexer service unavailable or unexpected failure |

**Response fields · HTTP 200 · application/json**

### POST /api/v1/wallets

Registered wallet addresses are synced automatically - transfers touching them are collected continuously and can be queried via the wallet transfer endpoints without polling the chain endpoints. ### GET /api/v1/transfers

**Get synced transfers across all registered wallets**

Returns the automatically synced transfer log across all the owner's registered wallets, merged and sorted by timestamp.

**Authentication:** ` X-API-KEY ` header required.

**Parameters**

<div className="indexer-fields">

| Name | Type | Details |
| --- | --- | --- |
| ` blockchain ` (query) | string | Required: No. Filter transfers by blockchain. Allowed values: ` "ethereum" `, ` "arbitrum" `, ` "avalanche" `, ` "polygon" `, ` "plasma" `, ` "sepolia" `, ` "tron" `, ` "ton" `, ` "bitcoin" `, ` "spark" `. |
| ` token ` (query) | string | Required: No. Filter transfers by token. Allowed values: ` "usdt" `, ` "xaut" `, ` "usat" `, ` "btc" `. |
| ` type ` (query) | string | Required: No. Filter by transfer direction relative to the wallet. Allowed values: ` "sent" `, ` "received" `. |
| ` from ` (query) | oneOf | Required: No. Start of the time range - timestamp in milliseconds or ISO 8601 date.  |
| ` to ` (query) | oneOf | Required: No. End of the time range - timestamp in milliseconds or ISO 8601 date.  |
| ` limit ` (query) | integer | Required: No. Maximum number of transfers to return. Minimum: ` 1 `. Maximum: ` 100 `. Default: ` 10 `. |
| ` skip ` (query) | integer | Required: No. Number of matching transfers to skip (pagination offset). Minimum: ` 0 `. Default: ` 0 `. |
| ` sort ` (query) | string | Required: No. Sort order by timestamp. Allowed values: ` "asc" `, ` "desc" `. Default: ` "desc" `. |

</div>

**Example request**

Replace path placeholders and the API key before running.

```bash
curl --request GET 'https://wdk-api.tether.io/api/v1/transfers' \
  --header 'X-API-KEY: <api-key>'
```
