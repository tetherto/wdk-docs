<Callout type="warn">
`@tetherto/wdk-uikit-react-native` is [deprecated and no longer maintained](https://www.npmjs.com/package/@tetherto/wdk-uikit-react-native), and has no replacement package. For new apps, build your own components, as the [React Native Starter](/examples-and-starters/react-native-starter) does in `src/components` and `src/theme`. These pages remain for existing apps.
</Callout>

This legacy reference covers the ready-made, themeable components in the WDK React Native UI Kit.
